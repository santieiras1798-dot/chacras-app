# Chacras App

Aplicación personal para registrar chacras por zafra y sincronizar información entre celular y computadora.

## V0.2
- Supabase conectado.
- Autenticación por usuario.
- Nueva chacra.
- Nueva zafra.
- Recorridas.
- Estados fenológicos según cultivo.
- Base preparada para Labores, Nutrición y Archivos.

El repositorio es privado y la aplicación está en desarrollo.
